# WOMEN Roadmap

WOMEN is an ongoing project. The current version provides the foundation, while some features still need further development and testing.

## 🚧 Development Needed

### Account & Backend
- Phone number OTP verification
- Username and account management
- One important/trusted contact system
- Secure backend authentication

### Live Audio
- Production WebRTC live audio
- Secure connection between the user and the selected important contact
- Emergency access-code verification
- Secure WebRTC signaling
- Connection recovery when the network is temporarily lost

### SMS
- Emergency SMS with date, time, battery and location
- "Go and hear live audio" option
- Secure emergency access information

### Bluetooth Rescue Mesh
- Reliable A → B → C → D multi-hop propagation
- Temporary relay during an active emergency
- Emergency packet expiry
- Duplicate packet prevention
- Approximate distance/RSSI indication
- Battery-efficient scanning and relaying

### Security & Privacy
- Security review
- Secure key management
- Better session protection
- Access-code protection
- Privacy testing

### Android Compatibility
- Test different Android versions
- Test different phone manufacturers
- Improve background reliability
- Improve battery usage
- Test locked-screen and reboot scenarios

### Testing
- Real-device testing
- Emergency scenario testing
- Offline testing
- Bluetooth testing
- Network failure and recovery testing

## 💡 Future Ideas

More improvements can be added as developers and users contribute ideas to the project.

## 🤝 Contributors

Developers interested in helping build WOMEN are welcome to contribute through issues, pull requests, testing, documentation, and feature development.
