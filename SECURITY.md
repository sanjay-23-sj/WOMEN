# Security

Security and privacy are important parts of WOMEN because the project deals with emergency situations and sensitive information.

## Reporting a Security Issue

If you find a security vulnerability in WOMEN, please do not publicly post sensitive details in a GitHub Issue.

Instead, contact the project maintainer privately and provide:

- A description of the issue
- Steps to reproduce it
- The affected feature or component
- Any relevant screenshots or logs

## Areas That Need Security Review

The following areas should receive careful security testing as the project develops:

- User authentication and OTP
- Important contact verification
- Emergency access codes
- WebRTC live audio
- Firebase/backend communication
- Bluetooth emergency packets
- Local emergency recordings
- Location information
- SMS links and emergency data
- Background services
- Local encryption and key management

## Responsible Disclosure

Please allow the issue to be reviewed and fixed before publicly disclosing technical details of a security vulnerability.

## Important

WOMEN is an open-source project under development. Contributors should not assume that every security-related feature is production-ready.

Safety-critical features should be thoroughly tested before real-world use.
