# Contributing to WOMEN

Thank you for your interest in WOMEN.

WOMEN is an open-source personal safety project. I started this project with the idea of creating a safety system that can work in both online and offline situations.

The current project is not the final version. Some features are already developed, while other parts still need improvement and further development.

I don't have enough time and financial resources to complete the entire project by myself, so I am sharing it on GitHub for developers who are interested in taking the project forward.

## How You Can Help

You can contribute by:

- Improving the existing Android code
- Fixing bugs
- Improving Bluetooth mesh communication
- Developing the WebRTC live audio system
- Working on Firebase/backend features
- Improving security and privacy
- Testing on different Android devices
- Improving battery usage
- Improving the UI and user experience
- Adding useful features
- Improving the documentation

## Before Contributing

Please understand the existing project and its architecture before making major changes.

If you find a problem or have a better idea, you can open an Issue and explain it.

If you want to contribute code, you can create a branch, make your changes, and submit a Pull Request.

## Important

WOMEN is a safety-related project, so reliability and privacy are very important.

Please test safety-related changes carefully before considering them ready for real-world use.

## Thank You

Whether you contribute code, report a problem, suggest an improvement, or simply share the project, thank you for helping WOMEN grow.
